# Pondera

Pondera es un proyecto personal de aprendizaje de Rust para gestionar
calificaciones, criterios de evaluación y competencias en el contexto de la
LOMLOE. La interfaz, TUI o GUI, aún no está decidida.

El repositorio contiene por ahora el proyecto binario inicial de Cargo. No se
ha implementado el registro de notas ni su cálculo. Durante el desarrollo solo
se usarán datos ficticios de alumnos.

Consulta [ESTADO.md](ESTADO.md) para conocer las decisiones confirmadas, las
dudas pendientes y el siguiente paso. [AGENTS.md](AGENTS.md) y
[CHATGPT.md](CHATGPT.md) describen la forma de trabajo con el tutor.
